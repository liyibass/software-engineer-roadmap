# comfy-1-1 畫布最小操作集：十個動作打天下

> **本章目標**：學會操作節點畫布——加、連、複製、刪、整理。這章沒有原理，純粹是把手指練熟，讓你之後能專心在概念上。

## 你會學到

- 十個最常用的畫布操作（其他的用到再說）
- 三種加節點的方式，以及最快的那個
- 為什麼「拉一條線出來放掉」是最好用的技巧
- Queue 之後怎麼看進度、怎麼取消

## 概念說明

### 心態：這是編輯器，不是畫圖工具

你在畫布上做的事，本質是**編輯一份資料**（那份 JSON）。所以它的操作邏輯比較接近 VS Code 或 Figma，而不是 Photoshop。

抱著「我在編輯一個流程圖」的心態，這些操作會很直覺。

### 十個動作

| # | 動作 | 怎麼做 |
|---|------|--------|
| 1 | **移動畫布** | 在空白處按住拖曳（或滑鼠中鍵拖曳） |
| 2 | **縮放** | 滾輪 |
| 3 | **加節點**（搜尋） | **在空白處雙擊** → 打字搜尋 → Enter |
| 4 | **加節點**（選單） | 在空白處右鍵 → Add Node → 分類選單 |
| 5 | **加節點**（拉線） | **從一個輸出孔拉線出來、放在空白處** → 自動列出接得上的節點 |
| 6 | **連線** | 從輸出孔拖到輸入孔 |
| 7 | **斷線** | 從**輸入孔**拉出來，放在空白處 |
| 8 | **複製節點** | 選取後 `Ctrl/Cmd + C` → `Ctrl/Cmd + V`（帶著連線複製是 `Ctrl + Shift + V`） |
| 9 | **刪除** | 選取後按 `Delete` |
| 10 | **執行** | `Queue Prompt` 按鈕，或 `Ctrl + Enter` |

> **只要記住第 3 和第 5 個就夠開始工作了。** 其他的用到自然會記得。

### 為什麼「拉線出來放掉」是最好用的技巧

第 5 個動作值得特別講。

假設你有一個 `Load Checkpoint` 節點，它有三個輸出孔（`MODEL` / `CLIP` / `VAE`），你不知道 `CLIP` 該接去哪裡。

```
從 CLIP 孔拉一條線出來 → 放在空白處
→ ComfyUI 會列出「所有吃 CLIP 當輸入的節點」
→ 選一個，它會自動建立節點並接好線
```

**這等於一個情境感知的說明書。** 對還不熟悉節點的人來說，這是最快的學習方式——你不用先知道有哪些節點，讓工具告訴你「接得上的有這些」。

> 這個技巧在 `comfy-1-15`（手接一張完整 workflow）會大量用到。

### 選取與多選

| 操作 | 做法 |
|------|------|
| 選一個 | 點節點標題列 |
| 加選 | `Shift + 點擊` |
| 框選 | 在空白處按住 `Ctrl` 拖曳出框（有些版本直接拖曳即可） |
| 全選 | `Ctrl/Cmd + A` |

多選之後可以一起移動、一起複製、一起刪除、或打包成 Group（見 `comfy-1-13`）。

### Queue 之後發生什麼

按下 `Queue Prompt` 之後：

```mermaid
graph LR
    A["按下 Queue"] --> B["整張圖打包成 JSON<br/>送給伺服器"]
    B --> C["排進佇列<br/>（可以連按好幾次排隊）"]
    C --> D["逐節點執行<br/>正在跑的節點會亮邊框"]
    D --> E["結果顯示在<br/>輸出節點上"]
```

這張圖在表達幾件事：

- **可以連按多次**：每按一次就排一個任務進佇列。想產四張不同 seed 的圖，就改 seed 按四次（或用 batch，見下面）。
- **執行中的節點會有視覺提示**（邊框發亮 / 進度條），這是判斷「卡在哪一步」的線索。
- **關掉瀏覽器不會停止任務**——真正在跑的是伺服器。

### 佇列的管理

介面上有佇列面板（Queue），可以：

- 看還有幾個任務在排隊
- 取消還沒開始的任務
- **中斷正在跑的任務**（Interrupt / Cancel）
- 看歷史紀錄，並且**點一下就把當時的 workflow 載回畫布**

> ⚠️ 最後一項很實用但常被忽略：**歷史紀錄可以還原當時的完整參數**。你調了半天覺得三十分鐘前那版比較好——去歷史裡找回來，不用重新調。

### 一次產多張：batch size vs 多次 Queue

兩種做法，差別要搞清楚：

| 做法 | 怎麼做 | 結果 |
|------|--------|------|
| **batch size = 4** | 在 `Empty Latent Image` 節點把 batch_size 設成 4 | 一次算四張，**共用同一個 seed 起點但各自不同**；快，但吃四倍 VRAM |
| **按四次 Queue** | seed 設成 randomize，連按四次 | 排四個獨立任務，慢一點，但 VRAM 需求不變 |

> **12GB 的實務建議**：一般解析度用 batch 4 沒問題（你的專案就是 4 張 832×1216 約 55 秒）。高解析度或掛了多個 ControlNet 時改用多次 Queue。

### 存檔與載入

| 操作 | 說明 |
|------|------|
| **Save / Export** | 存成 `.json`（UI 格式）。存在 `user/default/workflows/` |
| **Load** | 載入 `.json` |
| **拖曳一張 PNG 進畫布** | ⚠️ **會還原那張圖的完整 workflow** |

最後那個是 ComfyUI 最好用的特性之一：**它把 workflow 寫進產出圖的 metadata 裡**。所以任何一張 ComfyUI 產的圖，拖回畫布就能看到它是怎麼產的。

> 這也代表**分享圖片等於分享配方**——包括你的 prompt。要注意隱私的話，發布前記得清掉 metadata。完整說明見 `comfy-7-5`。

## 小練習

1. **練習拉線探索**：開一個 `Load Checkpoint` 節點，分別從 `MODEL`、`CLIP`、`VAE` 三個孔拉線出來放掉，看看各自能接哪些節點。**不用理解那些節點，只要感受一下「型別決定了能接什麼」。**

2. **玩壞再救回來**：把預設 workflow 的線全部斷開，然後試著自己接回去。接不回來就重新載入預設——**這個練習的重點是把手練熟，不是接對**。

3. **用 PNG 還原 workflow**：找一張你專案產的圖（`docs/reference/` 底下那些），拖進 ComfyUI 畫布，看看它還原出什麼。這招之後會常用。
